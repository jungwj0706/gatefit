# 데이터 출처 및 이용 조건

GATEFIT의 초기 출입구 데이터는 아래 공공데이터를 가공해 만들었습니다.

| 데이터셋 | 제공 | 원본 기준일 | 보존 파일 |
|---|---|---|---|
| [서울시 차량 출입구 정보 (OA-21700)](https://data.seoul.go.kr/dataList/OA-21700/S/1/datasetView.do) | 서울특별시, 서울 열린데이터광장 | 2022-12-10 | `raw/seoul/OA-21700_vehicle_entrances.zip` |
| [서울시 시설물 정보 (OA-21698)](https://data.seoul.go.kr/dataList/OA-21698/S/1/datasetView.do) | 서울특별시, 서울 열린데이터광장 | 2022-12-07 | `raw/seoul/OA-21698_facilities.zip` |

- 이용 조건: 공공누리 제1유형 (출처표시, 상업적 이용 및 변경 가능)
- 수집 시각과 원본 파일의 SHA-256은 `raw/seoul/manifest.json`에 기록되어 있습니다.
- 원본 파일은 수정하지 않고 그대로 보존합니다.

## 반드시 알아야 할 한계

두 데이터셋은 **일회성 사업으로 구축되었고 사업 종료 이후 현행화되지 않습니다.** (데이터 제공 페이지 명시)

따라서 GATEFIT은 이 데이터를 다음과 같이 다룹니다.

- 모든 레코드의 신뢰도 등급은 `PUBLIC_BASELINE`이며 `verified_at`은 비어 있습니다.
- 적합성 분석에서 이 데이터만으로는 `CONDITION_MATCH`(조건 충족)가 나오지 않고, 최대 `NEEDS_CONFIRMATION`(확인 필요)까지만 표시됩니다.
- 앱 화면에는 원본 기준일과 출처를 함께 표시합니다.
- 현장 또는 시설 공식 정보로 재검증한 레코드만 `VERIFIED_FIELD` / `VERIFIED_OFFICIAL`로 올릴 수 있으며, 검증 시각과 출처 없이는 데이터베이스 제약으로 등급 변경이 거부됩니다.

## 차량 제원

`curated/vehicle_model_specs.json`은 현대자동차 공식 카탈로그(PDF)의 제원표에서 직접 확인한 전장·전폭·전고입니다.

- 확인 날짜: 2026-11-11 (당시 게시된 현행 카탈로그 기준, 연식은 기록하지 않음)
- 각 항목에 카탈로그 URL을 함께 기록합니다.
- 카탈로그가 루프랙·휠 크기·트림에 따라 전고를 다르게 표기한 차종은 표기된 조건별로 나누어 넣었습니다.
- 카탈로그에 조건이 명확히 적히지 않은 값(예: 팰리세이드 하이루프의 전장)은 넣지 않았습니다.
- 카탈로그에는 "제원은 변경될 수 있다"는 안내가 있으므로, 앱은 제원을 적용할 때 사용자가 차량과 맞는지 확인하도록 안내합니다.

수록 차종: 아반떼, 쏘나타 디 엣지, 그랜저, 코나, 투싼, 싼타페, 팰리세이드, 아이오닉 5, 아이오닉 9, 스타리아, 스타리아 라운지

## 공휴일

`app/src/main/assets/calendar/kr_public_holidays.json`은 우주항공청이 발표한 월력요항의 관공서 공휴일(대체공휴일 포함)을 옮긴 것입니다.

- 수록 연도: 2026년, 2027년
- 수록되지 않은 연도는 공휴일 여부를 '미확인'으로 처리하며, 평일로 간주하지 않습니다.
- 월력요항 발표 이후에 지정되는 임시공휴일은 반영되지 않습니다.

## DEMO 데이터

`app/src/main/assets/demo/demo_places.json`은 화면 시연용 가상 시설입니다. 실제 시설이 아닙니다.

- 이름이 `DEMO`로 시작하고 좌표가 없으며, 앱 설정에서 직접 켠 경우에만 표시됩니다.
- 화면에 항상 DEMO 표시가 붙고, 내비게이션 안내와 제보 대상에서 제외됩니다.
- 실제 데이터 통계와 서버 데이터베이스에는 포함되지 않습니다.
